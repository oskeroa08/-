# Что изменено

## Визуал

- Первый экран: полноширинная вёрстка вместо «коробки» с полями; портрет перекадрирован (вертикальный кадр для десктопа + горизонтальный для мобильных через `<picture>`), голова и композиция кадра сохранены.
- Иконки фактов в шапке: убран двойной круг, пиктограммы перерисованы на сетке 24×24 с единым весом линий и воздухом внутри окружности.
- Иконки карточек услуг: «Диагностика» — документ с лупой, «Проектирование» — сетка-чертёж, «Сопровождение» — галочка в круге.
- Схемы кейсов переписаны на SVG-диаграммы: орг-дерево (кейс 01), радиальная схема SURA (кейс 02), дерево каналов (кейс 03). Соединители attach'атся точно к блокам, схемы масштабируются без поломок.
- Типографика: базовый кегль 15px, мелкий текст не мельче 10–11px, выправлена шкала размеров; теги кейсов — «пилюли», карточкам добавлены радиусы и мягкая тень при наведении.
- Логотип «БА.» перенесён в шапку и на десктопе; навигация подсвечивает активный раздел при прокрутке (scrollspy).

## Код

- `styles.css`: единая структура «токены → база → секции → медиа-запросы», удалён дублирующий слой правок поверх основного файла.
- Шрифт: Montserrat 400/500/600/700 вместо семи начертаний.
- `script.js`: IIFE + strict mode, scrollspy на IntersectionObserver, закрытие меню по Escape, пассивные слушатели.
- `index.html`: Open Graph, SVG-фавикон, `width/height` у изображений, `defer` у скрипта, aria-атрибуты сохранены и дополнены.
- Ассеты: два оптимизированных прогрессивных JPEG вместо одного «универсального» (меньше вес, точнее кадр).

## Перед публикацией

Укажите адрес получателя в `CONTACT_EMAIL` внутри `script.js` или подключите форму к CRM/серверному обработчику. Пока адрес не задан, обращение копируется в буфер обмена.
