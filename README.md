# Сайт бизнес-архитектора

Персональный сайт-визитка на чистом HTML, CSS и JavaScript — без сборщика и библиотек.

## Структура

- `index.html` — разметка, тексты, SVG-схемы кейсов
- `styles.css` — дизайн и адаптивность
- `script.js` — меню, закрепляемая шапка, scrollspy, появление блоков, форма
- `assets/portrait.jpg` — портрет на первом экране (кадрируется через `object-fit`)
- `404.html`, `.nojekyll` — для GitHub Pages

## Публикация (GitHub Pages)

1. Репозиторий → Settings → Pages → Source: `Deploy from a branch`, ветка `main`, папка `/ (root)`.
2. Свой домен: в том же разделе указать Custom domain (GitHub создаст файл `CNAME`) и включить Enforce HTTPS.
3. У регистратора домена:
   - apex-домен (`example.ru`): A-записи `185.199.108.153`, `185.199.109.153`, `185.199.110.153`, `185.199.111.153`;
   - поддомен (`www`): CNAME на `oskeroa08.github.io`.

## Перед запуском

- В `script.js` указать адрес в `CONTACT_EMAIL` — иначе форма только копирует обращение в буфер обмена.
- В `script.js` при желании указать `CONTACT_MAX_URL` (ссылка на профиль в MAX): под формой появятся прямые ссылки на почту и MAX.
- Проверить формулировки в кейсах 01 и 02: «примерно на 40% дороже сопоставимого предложения» (в тесте), рост выручки ×3 и затем ×2 (уточнить базу сравнения), «около 12% от выручки».
- Убедиться, что в текстах и метаданных нет названий компаний.
