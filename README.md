# Сайт бизнес-архитектора

Персональный сайт-визитка на чистом HTML, CSS и JavaScript — без сборщика и библиотек.

## Что в этой версии переработано

### Главный экран
- Первый экран снова полноширинный и полноэкранный (убрано «коробочное» сужение с пустыми полями по краям).
- Портрет перекадрирован под реальную пропорцию колонки: подготовлены два файла — вертикальный кадр для десктопа и горизонтальный для мобильных (`<picture>` сам выбирает нужный). Голова больше не обрезается, лицо по центру.
- Логотип «БА.» теперь виден и на десктопе слева, навигация — справа.

### Иконки
- Убран «двойной круг» (рамка + нарисованная окружность внутри SVG). Осталась одна аккуратная золотая окружность, внутри — компактная линейная пиктограмма с запасом воздуха.
- Пиктограммы перерисованы на единой сетке 24×24 с одинаковым весом линий (прицел/стратегия, график продаж, команда).

### Схемы в кейсах
- Все три визуальные схемы переписаны как настоящие SVG-диаграммы (вместо позиционирования отдельных div-блоков, из-за которого линии «висели в воздухе»):
  - **Кейс 01** — орг-дерево «Входящие обращения → Администратор → 2 менеджера / 2 менеджера» с ортогональными соединителями;
  - **Кейс 02** — радиальная схема «SURA» с центром и шестью модулями обучения, линии соединяются точно с чипами;
  - **Кейс 03** — дерево «Единая модель → Маркетплейсы / B2B / Корпоративные клиенты и сети».
- Схемы масштабируются под любую ширину и остаются читаемыми на мобильных.

### Код и производительность
- `styles.css` переписан в единую упорядоченную структуру (токены → база → секции → медиа), убран слой «доработок поверх», добавлены комментарии.
- Шрифт Montserrat сокращён с 7 начертаний до 4 (400/500/600/700) — заметно меньше грузится.
- `script.js` обёрнут в IIFE со строгим режимом; добавлен scrollspy — активный пункт меню подсвечивается при прокрутке, а не только по клику; меню закрывается по Escape.
- Добавлены метатеги Open Graph, SVG-фавикон, атрибуты `width/height` у изображений (нет скачков вёрстки), `defer` у скрипта.
- Увеличен базовый размер текста (тело 15px, мелкие подписи — не меньше 10–11px), выправлена типографическая шкала.

## Быстрый запуск

1. Распакуйте архив в отдельную папку.
2. Откройте `index.html` в браузере (или запустите `python3 -m http.server`).
3. Интернет нужен только для шрифта Montserrat; без сети используется системный шрифт.

## Структура

- `index.html` — разметка, тексты, SVG-схемы.
- `styles.css` — дизайн, адаптивность, анимации.
- `script.js` — мобильная навигация, scrollspy, появление блоков, обработчик формы.
- `assets/portrait-tall.jpg` — вертикальный кадр портрета (десктоп).
- `assets/portrait-wide.jpg` — горизонтальный кадр портрета (мобильные).

## Перед публикацией

1. В `script.js` укажите реальный адрес в переменной `CONTACT_EMAIL` (сейчас она намеренно пустая). Если адрес не задан, форма копирует текст обращения в буфер обмена.
2. При необходимости подключите форму к CRM или серверному обработчику.
3. Подтвердите проектные цифры и право на публикацию кейсов.
4. Добавьте фактические ссылки на Telegram и другие каналы связи, если нужны.
