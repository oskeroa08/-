САЙТ БИЗНЕС-АРХИТЕКТОРА

Быстрый запуск
1. Распакуйте архив в отдельную папку.
2. Откройте index.html в браузере.
3. Интернет нужен только для загрузки шрифта Montserrat; при отсутствии сети используется системный шрифт.

Структура
- index.html — содержание сайта, разметка и SVG-схемы кейсов.
- styles.css — дизайн, адаптивность, анимации (единая структура с комментариями).
- script.js — мобильная навигация, подсветка раздела при прокрутке, появление блоков, обработчик формы.
- assets/portrait-tall.jpg — вертикальный кадр портрета для десктопа.
- assets/portrait-wide.jpg — горизонтальный кадр портрета для мобильных.

Что изменено в этой версии
- Первый экран полноширинный; портрет перекадрирован под колонку (два кадра, выбирается автоматически), голова не обрезается.
- Иконки перерисованы: одна окружность вместо «двойного круга», единая сетка и вес линий.
- Схемы кейсов переписаны на SVG: орг-дерево, радиальная схема SURA, дерево каналов — линии точно соединяются с блоками.
- CSS переписан в единую структуру; шрифт сокращён до 4 начертаний; скрипт в строгом режиме со scrollspy.
- Добавлены Open Graph, фавикон, размеры изображений, увеличен базовый размер текста.

Перед публикацией
1. Откройте script.js и укажите реальный адрес в переменной CONTACT_EMAIL. Сейчас она намеренно пустая.
2. При необходимости подключите форму к CRM/серверному обработчику. Без адреса форма копирует текст обращения в буфер обмена.
3. Проверьте проектные цифры, формулировки и право на публикацию кейсов.
4. Добавьте фактические ссылки на Telegram или другие каналы связи, если они нужны.

Сайт сделан на чистом HTML, CSS и JavaScript, без сборщика и дополнительных библиотек.
