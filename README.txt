САЙТ БИЗНЕС-АРХИТЕКТОРА

Быстрый запуск
1. Распакуйте архив в отдельную папку.
2. Откройте index.html в браузере.
3. Интернет нужен только для загрузки шрифта Montserrat; при отсутствии сети используется системный шрифт.

Структура
- index.html — содержание сайта и разметка.
- styles.css — дизайн, адаптивность, анимации.
- script.js — мобильная навигация, появление блоков и обработчик контактной формы.
- assets/portrait.jpg — предоставленный оригинальный портрет.

Перед публикацией
1. Откройте script.js и укажите реальный адрес в переменной CONTACT_EMAIL. Сейчас она намеренно пустая, так как контактные данные не были предоставлены.
2. При необходимости подключите форму к CRM/серверному обработчику. В статической версии без бэкенда форма не отправляет данные автоматически; если e-mail не настроен, она копирует текст обращения в буфер обмена.
3. Проверьте проектные цифры, формулировки и право на публикацию кейсов. Кейс про обучение содержит показатели из исходной презентации, которые нужно подтвердить.
4. Добавьте фактические ссылки на Telegram или другие каналы связи, если они нужны.

Сайт сделан на чистом HTML, CSS и JavaScript, без сборщика и дополнительных библиотек.
